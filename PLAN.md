## Architecture

**Hub-and-Spoke · 3-Layer Serverless**

```
Browser (React Client Components)
    ↕  Server Actions (secure bridge — API keys never leave server)
Vercel Serverless Functions
    ↕                        ↕
Supabase                   Groq API
(PostgreSQL + RLS           (Llama 3.3 70B)
 + Auth + Storage)
```

**Mini-RAG AI Flow:**
1. User asks a question
2. Server Action fetches + aggregates last N trades
3. Context injected into Groq system prompt
4. Streaming response piped back to chat UI

## Rule Tracking (runs server-side on every trade save)

| Rule | Logic | Severity |
|---|---|---|
| Personal Daily Loss Limit | `net_pnl < −personal_daily_loss_limit` | 🟠 Warning banner |
| Firm Daily Loss Limit | `net_pnl < −daily_loss_limit` | 🔴 Critical modal + AI Guard flag |
| Max Drawdown | `account_size − balance > max_drawdown` | 🔴 Mark account `blown` |
| Profit Target | `balance − account_size ≥ profit_target` | 🏆 Prompt to mark `passed` |
| Consistency Rule | Free-text reminder displayed on dashboard | ℹ️ Informational |

**AI Guard also detects:**
- Revenge trade (prev loss + < 5 min gap)
- Consecutive losses (3+)
- Oversize position
- Emotional trade (direction + emotional state mismatch)
